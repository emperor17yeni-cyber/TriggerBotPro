# TriggerBot Pro — Minecraft 1.21 Fabric

Singleplayer-only client mod. Opens settings with **Right Shift**.

## Features
- Integrated-singleplayer guard; does not run on multiplayer servers.
- Entity filters: players, hostile, passive, neutral.
- Range, line-of-sight and invisibility/dead/creative filters.
- CPS range and randomized reaction delay.
- Critical-only mode and attack-key requirement.
- Four presets: Legit, Balanced, Fast, Crits.
- JSON config at `.minecraft/config/triggerbotpro.json`.
- Java 21 / Minecraft 1.21 / Fabric.

## Build
Run `gradlew.bat build` on Windows or `./gradlew build` on Linux/macOS.
The finished jar will be in `build/libs/`.
